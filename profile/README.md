<h2 align="center">⚙️ How We Work</h2>

We do not treat custom development as a commodity.

Before writing code, we work to understand the business context, the operational problem, the users involved, the technical constraints, and the risks that could affect delivery or maintenance.

Our delivery process is built around:

- clear scope and responsibilities;
- architecture proportional to the problem;
- incremental delivery and validation;
- practical documentation;
- secure handling of access and credentials;
- deployment planning;
- maintainable code;
- honest communication about risks, trade-offs, and next steps.

The goal is not to make software look complex. The goal is to make technology useful, stable, and easier to evolve.

<h2 align="center">🤝 Best Fit</h2>

BYTESIX is a strong fit for companies that:

- have operational processes that are still too manual;
- depend on spreadsheets, emails, or messages to run critical workflows;
- need a system that existing market tools do not solve well;
- have a legacy system that is becoming hard to maintain or extend;
- want to build a digital product with technical guidance from the beginning;
- need a reliable technical partner, not only someone to execute isolated tasks;
- value clarity, quality, documentation, and long-term thinking.

We are selective by design. Good software requires technical autonomy, realistic scope, responsible investment, and a shared commitment to building the right thing.

<h2 align="center">🧩 Selected Experience</h2>

<h3 align="center">🌎 SIA Hidreletricas</h3>

BYTESIX rebuilt and evolved **SIA Hidreletricas**, an environmental information system in production for the hydropower context.

The project demonstrates our ability to deliver complete software systems involving backend, frontend, database modeling, geospatial data, maps, infrastructure, deployment, documentation, support, and ongoing evolution.

Technologies and capabilities involved include TypeScript, NestJS, GraphQL, React, PostgreSQL, PostGIS, OpenLayers, modular architecture, and production system maintenance.

<h3 align="center">🧠 Technical Background</h3>

BYTESIX was founded by Luiz Bortoluzzi, a full-stack software developer with experience in Brazilian and international software projects, including demanding technical environments such as financial systems, web platforms, ERPs, HR systems, geospatial systems, integrations, and production-grade business applications.

That background shapes how BYTESIX works: technical execution matters, but direction, responsibility, and maintainability are what make software valuable over time.

<h2 align="center">💻 Technology</h2>

Our preferred stack for new projects is mature, productive, and easy to maintain:

- **Languages:** TypeScript, JavaScript, Python, SQL
- **Backend:** Node.js, NestJS, REST APIs, GraphQL
- **Frontend:** React, Next.js, Vite
- **Databases:** PostgreSQL, PostGIS, MySQL, MongoDB when appropriate
- **Infrastructure:** Linux, Docker, Docker Compose, NGINX, AWS, GitHub Actions
- **Quality:** modular architecture, clear data modeling, practical testing, deployment documentation, secure credential handling

Technology is chosen for fit, not fashion. The best technical decision is the one that solves the problem with quality, reasonable cost, and sustainable maintenance.
